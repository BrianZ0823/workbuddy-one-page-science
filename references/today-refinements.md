# 今天最终风格微调（权威态，覆盖 style-spec 的差异项）

`style-spec.md` 是模板 01 的基础美学定义。但在 2026-08-18 当天的多轮实测中，用户对成品做了以下最终调整——**以本文件为准**，它覆盖 style-spec 中的对应项。

## 字体（覆盖 style-spec "手写体/马克笔体"）
- 主标题：**黑体（SimHei / 黑体）**，不用 ZCOOL KuaiLe、Ma Shan Zheng 等卡通体。
- 正文：**微软雅黑（Microsoft YaHei，font-weight:500）** + `Noto Sans SC` 兜底；幼圆（YouYuan）弃用。
- 理由：用户明确要"正式、易读、非卡通"；实测幼圆中文字形不全（如"码""与"），浏览器会 fallback 到雅黑/Noto，造成同段混字、违和感强。

## 序号（禁用圆圈数字）
- 用户明确**不喜欢圆圈数字**。所有序号改为：
  - 方形/圆角矩形标签（如 `sc-no` 用 `border-radius:6px` 小标签，配色同卡片顶部色条）；
  - 或文字 `1. / 2.`；
  - 页面大序号用"左侧竖线分隔文字"（如 `ph-no`：`border-right` + 文字）。
- **禁止**圆形徽章、圆形角标。

## 便利贴（sticky-note）
- 改为与"一句话总结框（summary-box）"**并排 flex 布局**，不再绝对定位遮挡标题/副标题。
- 旋转约 2° 保留手账感。

## 卡片序号标签位置
- 置于卡片**左上角圆角矩形小标签**，颜色与卡片顶部色条一致（蓝/橙/绿/紫轮换）。

## 中文排版铁律
- 中文密集文案必须 HTML/CSS 确定性排版（可预览、可导出 PNG、零乱码）。
- **绝不**用 AI 生图承载中文（必乱码）。本技能默认纯 HTML/CSS 实现手账美学。

## 篇幅与完整性
- 篇幅按内容定，**不必强行压成一页纸**；覆盖要全。
- 名称/安装方法/步骤等关键信息不能模糊省略——每个条目都要有"明确可操作"的方法。

## 来源落款（可开关）
- 默认保留底部"来源/作者"落款（版权合规）。
- 若用户当次明确要求"去掉来源/署名"，则移除底部来源小字与署名（标题/卡片/金句原样保留）。
- 注：此开关与"保留作者+来源"红线并存——默认保留，仅在用户即时指令下关闭。

## 封面页留白控制
- 首页（`<section class="page cover">`）单独一套收紧样式，避免标题/摘要/路径条/速览之间出现大片空白。
- 关键数值：`.cover h1` 缩到 28px、`.handwrite-red` 缩到 17px 并减小旋转；summary-box 内边距从 18px/56px 降到 12px/44px；sticky-note 宽度加宽到 190px；path-bar/overview-grid/install-hint 的 margin/padding 统一收紧。

## 色板（HTML 实现用值，与 style-spec 暖米白一致）
- 纸 `#f7f3e8`（spec `#FFF9F2`），纸深色 `#efe9d8`，墨 `#2b2b2b`
- 强调：蓝 `#3b82f6` / 红 `#e94e3a` / 黄 `#ffe066` / 绿 `#8bc34a` / 紫 `#c084fc` / 橙 `#ffb366` / 青 `#5ac8fa`
- 卡片白底，顶部 6px 色条轮换（蓝/橙/绿/紫）
